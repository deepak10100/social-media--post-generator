# **App Name**: PostCraft AI

## Core Features:

- Social Media Post Generation: Generate complete social media posts for Instagram, Facebook, Twitter, LinkedIn, and Pinterest based on user-provided topics, objectives, and styles, outputting captions, hashtags and suggested image dimensions.
- AI Image Generation for Posts: Leverage AI to generate high-quality, realistic, and professional-looking images that match the post topic and style, enhancing visual appeal, or utilize stock photo search tool.
- Caption and Hashtag Suggestion: Suggest engaging captions with emojis and relevant, trending hashtags tailored to each social media platform.
- Platform Optimization: Automatically optimize generated content, including image dimensions and caption length, for each specific platform (Instagram, Facebook, etc.).
- Style Selection: Allow users to choose from various design styles (Minimalist, Bold, Modern, etc.) to align posts with their brand aesthetics.
- Post Template Saving: Enable users to save frequently used post templates for quick reuse and consistency in their social media strategy.
- Output structured data.: Create a structured JSON format to create automated processes and keep flexibility of the outputs.

## Style Guidelines:

- Primary color: Vivid blue (#29ABE2) to evoke trust and engagement, drawing users in.
- Background color: Light blue (#E1F5FE), almost white, provides a clean and modern canvas that highlights content.
- Accent color: Orange (#FF9800) adds energy and enthusiasm, used for call-to-action buttons and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern and neutral look.
- Simple and flat icons representing different social media platforms and post types.
- Clean and organized layout with clear sections for input fields, style options, and generated content previews.
- Subtle animations and transitions to enhance user experience without being distracting.
